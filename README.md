# Jornadas de Informática - IES Alixar

Proyecto colaborativo desarrollado para la Práctica 3
de Control de Versiones y Flujos de Trabajo.

## Descripción

Página web de las Jornadas de Informática del IES Alixar.

Permite consultar información del evento, visualizar
el programa de actividades y acceder al formulario
de inscripción.

## Tecnologías utilizadas

- HTML5
- CSS3
- Git
- GitHub

## Estructura del proyecto

- index.html: página principal.
- programa.html: programa de actividades.
- inscripcion.html: formulario de inscripción.
- css/styles.css: estilos de la web.
